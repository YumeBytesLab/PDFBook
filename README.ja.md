## 読みたい一冊を見つけて、続きのページへ。

フォルダにたまったPDFを、表紙で選べる本棚に。本、マンガ、論文、スキャン資料を、自分に合う表示で読めます。読書位置の記憶を有効にすれば、前回の続きから再開できます。

| 用途 | PDFBookでできること |
| --- | --- |
| **本・マンガ** | ページめくり・縦スクロール、単ページ・見開き、右綴じに対応。 |
| **論文・資料** | 文書内検索、しおり、PDF内の目次、最前面に置けるフローティングリーダー。 |
| **蔵書の整理** | 表紙、フォルダ、タグ、評価、お気に入り、読書状態、本ごとのメモ。監視フォルダを再スキャンして新しいファイルを取り込めます。 |
| **PDFツール** | JPG・PNG画像からPDFを作成。対応する文書・電子書籍の変換や、PDFに埋め込まれた画像の抽出も。 |
| **AIに質問** | 自分のプロバイダーやローカルのOllamaに接続。必要なときだけ使えます。 |

## 自分のPCに合うPDFBookを

**[最新リリース](https://github.com/YumeBytesLab/PDFBook/releases/latest)**から、OSとCPUに合うファイルを選んでください。

| OS | 配布形式 | CPU |
| --- | --- | --- |
| **Windows 10 / 11** | Setup・Portable | x64・ARM64 |
| **macOS** | DMG | Apple Silicon (ARM64)・Intel (x64) |
| **Linux** | AppImage・deb | x64 / amd64・ARM64 |

[インストールガイド](https://wiki.pdfbook.app/ja/download/) · [最初の一冊を追加する](https://wiki.pdfbook.app/ja/getting-started/)

<details>
<summary>初回起動とMicrosoft Store版について</summary>

Windowsの通常配布版は未署名、macOS版はDeveloper ID署名・公証を行っていません。初回起動時の確認はインストールガイドをご覧ください。

Microsoft Store版は公開準備中です。Windowsへの通常のインストールには **Setup** か **Portable** を使ってください。

</details>

## まずは無料で、自分の本棚を

| 機能 | 無料プラン | Pro / Lifetime |
| --- | --- | --- |
| **ライブラリ** | **50冊まで** | 冊数の制限なし |
| **フローティングリーダー** | 初回セッションは時間制限なし。その後は **月60分の実読時間** | 時間制限なし |
| **AIチャット** | 自分のプロバイダーで利用可能 | 自分のプロバイダーで利用可能 |
| **AIツール** | — | ページ読み取り・アプリ操作 |

外部AIプロバイダーの料金は別途かかります。PDFBookにAIサービスの利用料は含まれません。[現在の料金とプラン](https://pdfbook.app/ja#pricing)をご確認ください。

## ファイルは手元に。AIは必要なときに。

PDFの読書、ライブラリの保存、PDF作成・変換はPC内で動作します。**読むためのアカウント登録は不要です。** クラウドAIを使う場合は、メッセージ、会話の文脈、読み取りを依頼した文書のテキストやページ画像が設定先へ送信されます。ローカルのOllamaなら、AIへのリクエストも端末内で処理できます。

[プライバシーポリシー](https://pdfbook.app/ja/privacy) · [AIの使い方](https://wiki.pdfbook.app/ja/features/ai-assistant/)

### このリポジトリについて
