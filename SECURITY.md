# Security policy

PDFBook itself is closed source. This public repository contains the documentation site and release binaries.

## Reporting a vulnerability

Please do not post exploit details, sensitive logs, API keys, document contents, or other private data in a public issue.

If GitHub offers **Private vulnerability reporting** for this repository, use the **Security** tab to send the report privately. If that option is unavailable, open a public issue asking for a private contact channel without including the vulnerability details.

A useful report includes:

- the PDFBook version and operating system;
- the affected feature;
- clear reproduction steps;
- the security impact;
- any relevant crash output or screenshots with personal data removed.

For ordinary bugs and feature requests, use the public issue tracker.

## Scope

Security reports may cover the distributed PDFBook application, installers and portable builds, update behavior, local file handling, PDF parsing, screen capture, AI-provider integration, and this documentation site.
