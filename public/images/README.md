# Product images

`app-icon.png` is an unchanged copy of the official website's `public/icon-512.png` (512 × 512), copied on 2026-10-15. It is the existing PDFBook app mark, used for the README header.

The screenshots below are unchanged copies of real PDFBook 1.1.0 captures used on the official website, pdfbook.app. The example books are demonstration documents.

- `library-en.webp` and `library-ja.webp`: library, 1920 × 1200.
- `reader-en.webp` and `reader-ja.webp`: reader, 1920 × 1200.

Source: the official website's `public/product/` media directory, copied on 2026-10-15. PDFBook 1.1.1 changes release packaging, without a new reader or library interface.

These are application captures, not generated interface mockups. Keep the files local to this repository so the README and documentation do not depend on an external screenshot service.

Only English and Japanese screenshots are currently provided. Other README translations label their screenshots as the English interface; they do not imply that the captured screens are localized.
