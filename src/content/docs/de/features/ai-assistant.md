## Anbieter verbinden

Bookie ist freiwillig nutzbar. Wähle unter **Einstellungen → KI** Ollama, OpenAI, Anthropic (Claude), OpenRouter oder Gemini. Trage deinen API-Schlüssel oder die Ollama-Adresse ein und wähle ein verfügbares Modell.

Bei Cloud-Anbietern bestätigst du den Datenhinweis. PDFBook enthält kein KI-Abo und kein API-Guthaben. Für Texte und Seitenbilder können Gebühren beim Anbieter entstehen.

## Lokales Ollama

Starte Ollama und installiere ein kompatibles Modell. Prüfe Server-URL und Modellliste im KI-Tab. Bei leerer Liste kontrollierst du Server und installierte Modelle. Nur ein lokaler Server hält diese Anfragen auf dem Gerät; eine entfernte URL bleibt ein entfernter Dienst.

## Chat und Dokumentwerkzeuge

Kostenlose Nutzer können chatten. Seiten oder Cover lesen und App-Aktionen ausführen erfordert einen bezahlten Tarif. Ein geöffnetes PDF wird nicht automatisch vollständig an das Modell gegeben.

Seitentools können Text, ein gerendertes Bild oder beides liefern. Scans brauchen ein bildfähiges Modell. Aktionen hängen von freigegebenen Werkzeugen und Berechtigungen ab. Vergleiche Antworten mit der echten Seite; sie können falsch sein.

## Daten im Cloud-Betrieb

Nachrichten, Gesprächskontext, Buchmetadaten und angeforderte Texte oder Seitenbilder können an deinen Anbieter gehen. Du kannst lokal arbeiten oder ohne KI lesen. Siehe [Datenschutz](/de/privacy/) und [Tarife](/de/plans-and-licenses/).
