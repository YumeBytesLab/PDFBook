## Scegli il provider

Bookie è facoltativo. In **Impostazioni → IA** scegli Ollama, OpenAI, Anthropic (Claude), OpenRouter o Gemini. Inserisci la chiave API o l’indirizzo Ollama e seleziona un modello disponibile.

I provider cloud richiedono conferma dell’avviso dati. PDFBook non include abbonamenti o crediti IA. Il provider può addebitare testo e immagini di pagina.

## Ollama locale

Avvia Ollama e installa un modello compatibile. Controlla URL e lista nella scheda IA. Se è vuota, verifica server e modello installato. Le richieste restano sul computer quando il server configurato è locale. Un indirizzo remoto resta un servizio remoto.

## Chat e strumenti

Gli utenti gratuiti possono conversare. Leggere pagine o copertine ed eseguire azioni nell’app richiede un piano a pagamento. Aprire un PDF non fornisce automaticamente tutto il documento al modello.

Gli strumenti possono inviare testo, immagine di pagina o entrambi. Le scansioni richiedono un modello capace di interpretare immagini. Le azioni dipendono da strumenti e permessi abilitati. Verifica le risposte sulla pagina originale: possono essere sbagliate.

## Dati inviati

Messaggi, contesto, metadati e testi o immagini richiesti possono arrivare al provider cloud scelto. Puoi usare un modello locale o leggere senza IA. Consulta [privacy](/it/privacy/) e [piani](/it/plans-and-licenses/).
