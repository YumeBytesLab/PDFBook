## Scegli il file

Apri l’**[ultima versione ufficiale](https://github.com/YumeBytesLab/PDFBook/releases/latest)**. Il nome completo contiene anche la versione e termina così:

| Computer | File |
| --- | --- |
| Windows, Intel/AMD | `windows-x64-setup.exe` o `windows-x64-portable.exe` |
| Windows on Arm | `windows-arm64-setup.exe` o `windows-arm64-portable.exe` |
| Mac, Apple Silicon | `macos-arm64.dmg` |
| Mac, Intel | `macos-x64.dmg` |
| Linux, Intel/AMD | `linux-x64.AppImage` o `linux-amd64.deb` |
| Linux, Arm | `linux-arm64.AppImage` o `linux-arm64.deb` |

`x64`, `amd64` e il vecchio `x86_64` indicano la stessa famiglia. Serve Windows 10 build 19041 o successiva, incluso Windows 11.

## Windows

Setup installa normalmente. Portable funziona senza installare. Le versioni autonome non sono firmate e Windows può avvisare su autore o reputazione. Verifica l’origine ufficiale prima di eseguirle.

La distribuzione su Microsoft Store è in preparazione. Su Windows scegli **Setup** o **Portable**.

## macOS e Linux

Apri il DMG e trascina PDFBook in Applications. Le versioni Mac non hanno firma Developer ID né autenticazione Apple. Se l’avvio è bloccato consulta [Apple](https://support.apple.com/it-it/102445). Su Linux consenti l’esecuzione dell’AppImage o installa il deb con il gestore pacchetti. La cattura richiede X11.

## Aggiorna

In **Impostazioni → Avanzate** controlla manualmente o abilita la ricerca all’avvio. Quando cambi computer conserva PDF e dati dell’app. Dopo l’installazione puoi [aggiungere il primo libro](/it/getting-started/).
