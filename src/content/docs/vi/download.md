## Chọn đúng tệp

Mở **[bản phát hành chính thức mới nhất](https://github.com/YumeBytesLab/PDFBook/releases/latest)**. Tên đầy đủ có phiên bản và kết thúc như sau:

| Máy tính | Tệp |
| --- | --- |
| Windows, Intel/AMD | `windows-x64-setup.exe` hoặc `windows-x64-portable.exe` |
| Windows on Arm | `windows-arm64-setup.exe` hoặc `windows-arm64-portable.exe` |
| Mac, Apple Silicon | `macos-arm64.dmg` |
| Mac, Intel | `macos-x64.dmg` |
| Linux, Intel/AMD | `linux-x64.AppImage` hoặc `linux-amd64.deb` |
| Linux, Arm | `linux-arm64.AppImage` hoặc `linux-arm64.deb` |

`x64`, `amd64` và tên cũ `x86_64` chỉ cùng họ CPU. Windows cần Windows 10 build 19041 trở lên, gồm Windows 11.

## Windows

Setup cài thông thường; Portable chạy không cần cài. Bản độc lập chưa ký nên Windows có thể cảnh báo nhà phát hành hoặc uy tín. Kiểm tra nguồn chính thức trước khi quyết định chạy.

Bản Microsoft Store đang được chuẩn bị. Trên Windows, hãy chọn **Setup** hoặc **Portable**.

## macOS và Linux

Mở DMG và kéo PDFBook vào Applications. Bản Mac chưa có chữ ký Developer ID hay công chứng Apple; xem [hướng dẫn Apple](https://support.apple.com/vi-vn/102445) nếu bị chặn. Trên Linux, cấp quyền thực thi cho AppImage hoặc cài deb bằng trình quản lý gói. Chụp màn hình cần X11.

## Cập nhật

Trong **Cài đặt → Nâng cao**, kiểm tra thủ công hoặc bật kiểm tra lúc mở. Khi chuyển máy, giữ PDF gốc và bản sao dữ liệu ứng dụng. Sau khi cài, hãy [thêm cuốn sách đầu tiên](/vi/getting-started/).
