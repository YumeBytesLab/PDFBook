## Appearance and language

Open **Settings → General**. Choose light, dark or system appearance, an accent color and interface text size. All **12 interface languages** are selectable here. Replay the intro guide if you want to revisit the main screens.

The default-PDF action follows your OS: Windows opens Default Apps settings, macOS uses Finder's application choice, and Linux can set an association when supported. Available Windows standalone builds may also show Explorer thumbnails. This integration is not included in Store packages.

## Reader defaults

In **Reader**, choose the default layout, single or double pages, reading direction, initial zoom, reading-position memory, focus behavior and page-flip sound. Some choices can be overridden for an individual book.

Performance choices switch the PDF rendering engine. If a particular document draws incorrectly, try the other engine and reopen the PDF. Avoid assuming that one engine is always faster for every document.

## Library behavior

In **Library**, choose the initial sort order, click-to-open behavior and whether a folder view includes subfolder books. Thumbnail prefetch and concurrency affect how eagerly covers are prepared. Reduce concurrency if your computer becomes busy.

## Backup and restore

**Settings → Advanced → Backup and restore**

Transfer your library, folders, reading positions, bookmarks, covers and display settings between editions or computers. [Backup and restore](/privacy/)

## Updates, data and connected services

**Advanced** contains the startup update preference, manual update check and **Open user data folder**. Use the data-folder action when making a backup or collecting a specific support file.

Provider/model settings live in **AI**. Activation and device management live in **License**. For their data and plan implications, read [AI setup](/features/ai-assistant/), [licenses](/plans-and-licenses/) and [privacy](/privacy/).
