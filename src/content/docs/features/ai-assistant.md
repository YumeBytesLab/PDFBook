**Bookie** is PDFBook's optional reading assistant. Configure a provider and model in **Settings → AI**, then open the assistant when you want to chat.

## Choose a provider

Supported options include Ollama, OpenAI, Anthropic (Claude), and OpenRouter. You supply the provider account or local model. PDFBook does not include a paid AI subscription; cloud usage may have its own charges.

With Ollama running locally, AI requests can stay on your computer. With a cloud service, requests go to that provider.

## Plan limits and document access

Free users can chat. Tools that read the current PDF page or cover, or act inside the app, require a paid PDFBook plan. The assistant does not automatically read the whole document simply because you opened it.

Page-reading tools can provide extracted text, a rendered page image, or both, depending on the PDF. That lets a compatible model discuss the requested page. Results depend on the selected model and can be incorrect.

## Privacy

Requests can include messages, chat context, book metadata, and document text or page images requested through tools. When you use a cloud provider, that content is sent to the provider you configured. Check its data-handling terms before sharing private material.

You can read and organize PDFs without configuring or using AI. See the [privacy policy](https://pdfbook.app/privacy) and [FAQ](/faq/).
