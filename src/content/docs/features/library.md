## Bring in local files

In **Library**, choose **Add book** to add a book or **Add sync path** to include a folder. PDFBook validates the PDFs and builds cover thumbnails. The originals remain in their existing locations.

Use **Sync files** to re-scan registered folders when files change. Startup scans can also refresh them. A sync path does not mean live background monitoring; files added later may need a new scan.

## Make the shelf easy to browse

Switch between cover and list views. Use title, author, folders, tags, favorites, a 0–5 star rating and Unread / Reading / Completed status to keep a collection useful. Search, filters and sort order help narrow it down.

Open a book's details to edit its information, description and book-level notes. Folder grouping in the library does not itself move a PDF to a new disk location. Reader direction and saved position can be remembered per book.

## Removing a book

Removing an entry from the catalog leaves the original PDF on disk. Removed books are excluded from later automatic folder scans. If a file is moved or renamed outside the app, its saved path may stop working; restore that location or add the file from its new location.

## Limits and backups

The Free plan supports **50 books**; paid plans remove the library cap. Your catalog, settings and thumbnails are local. Back up both the application data and the original PDFs, because the catalog is not a copy of the books. See [files and privacy](/privacy/) for the backup procedure.
