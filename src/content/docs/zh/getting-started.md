## 安装并调整界面

在[安装指南](/zh/download/)中选择适合系统与 CPU 的版本。启动 PDFBook 后，可以完成或跳过首次引导。阅读本地 PDF 不需要账户，也不需要配置 AI。

打开 **设置 → 常规**，选择界面语言、外观与文字大小。需要重新熟悉操作时，也可在此再次显示引导。

## 添加书籍或文件夹

1. 从侧栏打开 **书库**。
2. 使用 **添加书籍** 添加单个 PDF，或通过 **添加同步路径** 注册一个 PDF 文件夹。
3. 等待文件验证和封面生成，然后打开书籍。

原始 PDF 保留在原来的文件夹。书库记录文件位置和阅读信息，不会自动生成备份副本。免费书库最多可添加 **50 本书**。

## 选择阅读方式

使用 **翻页模式** 翻页，或选择 **纵向滚动** 连续滚动。漫画可使用双页与从右向左阅读。需要下次继续阅读时，请在阅读器设置中启用阅读位置记忆。

## 导入后来添加的文件

向已注册的文件夹放入新 PDF 后，点击 **同步文件** 重新扫描。启动时的扫描也可更新书库。这里的同步不是持续在后台监视文件变化。

接下来可查看[阅读器操作](/zh/features/reader/)、[书库整理](/zh/features/library/)和[PDF 工具](/zh/features/creating-pdfs/)。保留原始文件，尤其是在移动或重命名文件夹之前。
