## 本地阅读和保存

PDF 阅读、书库保存、创建、转换与图片提取在本机运行。阅读本地文件无需账户。书库保存的是路径和资料，不会把原始 PDF 替换成云端副本。

在应用外移动或重命名文件后，记录的路径可能失效。请保持原始文件可访问，包括外接硬盘上的文件，并为它们单独备份。

## 进行完整备份

1. 打开 **设置 → 高级 → 打开用户数据文件夹**。
2. 退出 PDFBook，避免复制时数据继续变化。
3. 同时备份应用数据文件夹和原始 PDF 文件夹。

`library.json` 保存书库，`preferences.json` 保存设置，`thumbnails/` 保存封面。其他文件可能包含聊天记录、记住的文档密码、许可证数据与服务商配置，因此请将备份作为私人资料保管。只复制 `library.json` 并不包含书籍内容。

## 由你选择的网络功能

打开 PDF 链接会下载该文件。启用启动更新检查会连接 GitHub，付费许可证激活与验证会连接认证服务。这些网络功能与本地 PDF 绘制不同。

使用云端 AI 时，消息、上下文、书籍资料及请求的文档文本或页面图片可能发送给所选服务商。Ollama 地址在本机时可本地处理。远程 Ollama 地址依然属于远程服务。

## 发送支持资料

优先提供复现步骤和可公开的样例，删除 API 密钥、许可证密钥、保存的密码和私人文档。完整服务条款见[隐私政策](https://pdfbook.app/privacy)，连接方式见[AI 指南](/zh/features/ai-assistant/)。不要直接公开整个应用数据目录。
