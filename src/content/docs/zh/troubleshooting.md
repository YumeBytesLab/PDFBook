## 书籍无法打开

检查原始 PDF 是否仍在记录的位置，外接硬盘是否已连接。文件移动后，可恢复原位置或从新位置添加。向同步文件夹加入文件后，需要重新扫描。书库记录不是 PDF 的备份副本。

如果要求密码，请输入该文档的密码；许可证密钥不是 PDF 密码。

## 搜索或显示不正常

纯图片扫描没有文字层时无法搜索，应用不包含 OCR。目录为空也可能是原 PDF 没有目录。遇到乱码或绘制缺失，可在 **设置 → 阅读器** 尝试另一种渲染引擎，并重新打开文档。反馈时请使用不含私人内容的样例。

## PDF 工具失败

创建器只接受 JPG/PNG。转换器需要支持的格式，会跳过 DRM 保护文件；也请检查输出目录是否可写。提取器只保存内嵌图片，所以纯文字或矢量页面可能没有结果，提取成功也不等于导出了完整页面。

## 采集、AI 或付费功能不可用

采集需要 Windows 或 Linux X11，自动翻页还有独立条件。AI 请检查服务商密钥、模型、网络或本地 Ollama 服务，以及请求是否需要付费工具。付费功能请联网验证许可证，并核对有效期和设备上限。

## 提交有用的反馈

先检查版本并尝试最新发行版。在[问题报告](https://github.com/YumeBytesLab/PDFBook/issues/new/choose)中填写版本、系统、CPU、操作步骤、预期结果和实际结果。不要上传私人 PDF、密钥或完整数据目录。私人咨询请[联系支持](https://pdfbook.app/contact)，安全漏洞请按[安全政策](https://github.com/YumeBytesLab/PDFBook/security/policy)报告。
