## 将图片合成为 PDF

1. 打开 **生成器**，选择 **添加图片** 或 **选择文件夹**。
2. 添加 JPG/PNG 图片，检查并调整页序。文件夹导入采用文件名自然排序，导出前请确认顺序。
3. 选择纸张大小、图片适配方式与页边距，需要时设置打开密码。
4. 点击 **创建 PDF**，指定保存位置。

加密输出需要所设置的密码才能打开，请妥善保存。创建器只接受图片，不接受 WebP，也不能任意导入其他 PDF 的页面。

## 转换文档与电子书

打开 **转换器** 添加文件，选择输出文件夹并开始转换。可以设置是否将成功生成的 PDF 加入书库。

支持的扩展名包括 EPUB/KEPUB、MOBI、AZW/AZW3/KF8、DOCX、MD/Markdown、TXT/Text、HTML/HTM 和 CBZ/CBR。阅读器打开的是转换后的 PDF，不是直接阅读 EPUB。DRM 保护文件会被跳过，复杂排版也可能发生变化。删除原文件之前，请先检查转换结果。

## 提取 PDF 内嵌图片

在 **提取器** 中选择 **选择 PDF**，等待图片预览。选择部分图片或全部保存到文件夹，输出格式为 PNG。受密码保护的 PDF 会要求输入密码。

提取的是内嵌图片对象，而不是完整页面截图，也不是将指定页分割为新 PDF。只有文字和矢量线条的页面可能没有可提取图片。若要收集其他应用正在显示的页面，请在支持的系统使用[屏幕采集](/zh/features/screen-capture/)。
