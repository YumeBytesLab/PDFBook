## 先检查系统支持

屏幕采集支持 Windows 和 Linux X11，在 macOS 与 Linux Wayland 中禁用。自动翻页是另一项能力，取决于键盘辅助组件、CPU 架构与权限。Linux ARM64 可在 X11 下采集，但没有自动翻页辅助组件。

应用会显示当前可用的能力。即使采集入口不可用，也仍能使用已经保存的 JPG/PNG 图片创建 PDF。

## 选择窗口并采集

1. 打开 **生成器** 并选择 **从屏幕捕获**。
2. 选择目标窗口与采集区域，裁掉不需要的工具栏或空白。
3. 设置页数与等待时间。如果支持自动翻页，选择按键或方向，并留出足够时间让目标应用完成绘制。
4. 开始采集，检查得到的图片，再在创建器中调整顺序并导出 PDF。

采集期间请保持目标窗口可用。窗口最小化、内容未变化或当前显示不正确时，无法得到期望的下一页。

## 页面重复或空白

先只采集一个可见页面，确认窗口选择与显示状态。若拍到了翻页动画过程，请增加等待时间。自动翻页不可用不代表屏幕采集本身损坏；查看能力提示，并考虑使用图片输入等可用方式。

采集只记录可见画面，不会导入目标应用的原始文档，不会添加 OCR，也不会恢复隐藏页面。一般的图片合成步骤见[PDF 工具](/zh/features/creating-pdfs/)。如需反馈问题，请提供系统、CPU 和操作步骤，避免上传私人文档。
