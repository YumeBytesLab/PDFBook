## 按书籍选择布局

从 **书库** 或 **阅读器** 打开 PDF。工具栏可切换 **翻页模式** 与 **纵向滚动**，翻页模式可选择单页或双页。

漫画可在显示设置中选择从右向左阅读。阅读方向能按书保存，因此可在同一书库中管理不同阅读方向的漫画和资料。扫描尺寸不合适时调整缩放，用页码控件跳到指定位置。

## 搜索并记住位置

文本搜索需要 PDF 本身有可搜索的文字层。纯图片扫描不会自动获得 OCR。目录面板显示文档自带的目录。没有内置目录的 PDF 可能不显示条目。

给当前页添加书签，可选择设置名称，再从书签面板返回。在 **设置 → 阅读器** 开启阅读位置记忆，下次即可从上次停下的位置继续。

## 边工作边阅读

专注模式可隐藏周围界面。悬浮阅读器会打开一个始终置顶的窗口，方便与笔记或其他应用并排使用。

首次免费悬浮阅读会话不限时，之后每个自然月提供 **60 分钟实际阅读时间**。额度按 UTC 月初重置。Pro 与 Lifetime 不受此时间限制，详情见[方案说明](/zh/plans-and-licenses/)。

## 密码与笔记

受保护的 PDF 需要输入文档密码，也可按书记住。书库中的笔记属于整本书，不是 PDF 页面上的批注。应用不提供高亮、手绘或页面注释。出现显示问题时，可查阅[故障排查](/zh/troubleshooting/)。
