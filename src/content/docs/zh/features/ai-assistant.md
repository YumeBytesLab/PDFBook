## 连接服务商

Bookie 是可选的阅读助手。在 **设置 → AI** 选择 Ollama、OpenAI、Anthropic（Claude）、OpenRouter 或 Gemini，填写 API 密钥或本地 Ollama 地址，再选择可用模型。

使用云端服务商时，需要确认数据共享说明。PDFBook 不包含外部 AI 订阅或 API 额度。文本、页面图片等请求可能按服务商规则单独收费。

## 使用本地 Ollama

先在电脑上运行 Ollama 并安装兼容模型。在 AI 设置中确认服务器 URL 和模型列表。列表为空时，请检查服务是否启动、模型是否已安装。只有配置的地址是本地服务器时，这些 AI 请求才留在本机。远程地址仍是远程服务。

## 聊天与文档工具

打开助手并发送问题。免费用户可以聊天。读取页面或封面、操作应用的工具需要 PDFBook 付费方案。仅仅打开 PDF 不会自动将整份文档提供给模型。

页面工具可能返回文本、页面渲染图片或两者。分析扫描与图表需要能理解图片的模型。应用操作取决于启用的工具与权限。AI 可能回答错误，请与原始页面核对重要内容。

## 发送到云端的内容

请求可能包含消息、会话上下文、书籍资料，以及通过工具请求的文档文本或页面图片，这些内容会发送给配置的服务商。不希望发送时，可选择本地模型，或完全不使用 AI 来阅读。详情见[隐私](/zh/privacy/)和[方案](/zh/plans-and-licenses/)。
