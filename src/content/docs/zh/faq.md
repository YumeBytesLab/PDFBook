## 可以免费使用且不注册账户吗？

可以。本地阅读不需要账户。免费书库支持 50 本书；悬浮阅读器首次会话不限时，之后每个自然月有 60 分钟实际阅读时间。付费功能与认证条件见[方案](/zh/plans-and-licenses/)。

## 能阅读漫画或 EPUB 吗？

漫画 PDF 支持从右向左、单页、双页与纵向滚动。EPUB 等支持的电子书先通过转换器变成 PDF 再阅读。CBZ/CBR 也可转换，DRM 保护来源会被跳过。

## 文件夹同步会上传收藏吗？

不会。同步路径重新扫描本地文件夹并更新书库，不是云同步，也不是持续监视文件系统。备份时请同时保存原始 PDF 和应用数据。

## 有高亮、OCR 或 PDF 分页吗？

这些工具不包含在应用中。阅读器有书签和整本书的笔记；提取器保存内嵌图片，不会将一段页面另存为新 PDF。创建器通过 JPG/PNG 图片制作 PDF。

## 包含 AI 费用吗？会读取所有书吗？

AI 是可选项，连接自己的服务商或本地 Ollama，外部费用另计。免费用户可聊天，页面读取与应用操作需要付费方案。打开书籍不会自动上传全文，但云端请求可能发送所请求的文本、页面图片与上下文。

## 为什么某些功能在我的电脑上不可用？

屏幕采集支持 Windows 和 Linux X11，在 macOS 与 Wayland 禁用。自动翻页还依赖辅助组件与 CPU 架构。Microsoft Store 版正在准备中，目前请在[下载页](/zh/download/)选择普通发行版。具体问题可继续查看[故障排查](/zh/troubleshooting/)。
