## 읽기와 로컬 저장

PDF 읽기, 라이브러리 저장, PDF 생성·변환과 이미지 추출은 컴퓨터에서 실행됩니다. 로컬 파일 읽기에 계정은 필요하지 않습니다. 라이브러리는 경로와 정보를 기록하며 원본을 클라우드 사본으로 바꾸지 않습니다.

앱 밖에서 PDF를 이동하거나 이름을 바꾸면 저장된 경로가 끊길 수 있습니다. 외장 드라이브를 포함해 원본을 사용할 수 있는 상태로 유지하고 따로 백업하세요.

## 제대로 백업하기

1. **설정 → 고급 → 사용자 데이터 폴더 열기**를 엽니다.
2. 복사 중 데이터가 바뀌지 않도록 PDFBook을 종료합니다.
3. 앱 데이터 폴더와 원본 PDF 폴더를 모두 백업합니다.

`library.json`은 카탈로그, `preferences.json`은 설정, `thumbnails/`는 표지입니다. 다른 파일에는 대화 기록, 기억한 문서 암호, 라이선스와 제공업체 설정이 포함될 수 있으므로 백업을 비공개로 보관하세요. `library.json`만 복사하면 책 본문은 백업되지 않습니다.

## 선택한 네트워크 기능

PDF URL을 열면 그 파일을 내려받습니다. 시작 시 업데이트 확인은 GitHub, 유료 인증과 검증은 라이선스 서비스에 연결합니다. 로컬 PDF 표시와는 별도 기능입니다.

클라우드 AI는 메시지, 문맥, 책 정보와 요청한 문서 텍스트·페이지 이미지를 선택한 제공업체에 보낼 수 있습니다. Ollama도 원격 URL이라면 원격 서비스입니다. 로컬 서버를 사용할 때 해당 요청이 기기 안에서 처리됩니다.

## 지원 자료 보내기

재현 단계와 공개 가능한 예제를 우선 사용하고 API 키, 라이선스 키, 암호와 개인 문서를 제거하세요. 전체 정책은 [개인정보 처리방침](https://pdfbook.app/privacy), 연결 방법은 [AI 가이드](/ko/features/ai-assistant/)에서 확인할 수 있습니다. 앱 데이터 전체를 공개 첨부하지 마세요.
