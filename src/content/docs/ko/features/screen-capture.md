## 지원 환경 확인

화면 캡처는 Windows와 Linux X11에서 사용할 수 있으며 macOS와 Linux Wayland에서는 비활성화됩니다. 자동 페이지 넘김은 별도 기능으로 키보드 도우미, CPU 구조와 권한에 따라 달라집니다. Linux ARM64는 X11에서 캡처할 수 있지만 자동 넘김 도우미는 없습니다.

앱이 사용 가능한 기능을 안내합니다. 캡처 버튼이 비활성화되어도 저장된 JPG/PNG 이미지로 PDF를 만드는 기능은 사용할 수 있습니다.

## 창 선택과 캡처

1. **생성기**에서 **화면에서 캡처**를 선택합니다.
2. 대상 창과 캡처 영역을 고르고, 원하지 않는 도구 모음과 여백을 잘라냅니다.
3. 페이지 수와 대기 시간을 설정합니다. 자동 넘김이 가능하면 키나 방향을 고르고 대상 앱이 그리기를 마칠 시간을 확보하세요.
4. 캡처를 시작한 뒤 이미지를 확인하고 Creator에서 순서를 정리해 PDF로 내보냅니다.

캡처 중에는 대상 창을 사용할 수 있는 상태로 유지하세요. 최소화되었거나 페이지가 바뀌지 않으면 원하는 다음 페이지를 얻을 수 없습니다.

## 반복 페이지나 빈 화면

먼저 한 페이지만 캡처해 선택과 표시 상태를 확인하세요. 넘김 애니메이션 도중 촬영되면 대기 시간을 늘립니다. 자동 넘김이 없다고 캡처 전체가 고장 난 것은 아닙니다. 기능 안내를 확인하고 이미지 입력 등 가능한 방법을 선택하세요.

화면 캡처는 보이는 내용을 수집합니다. 원본 문서 가져오기, OCR, 숨겨진 페이지 복원은 하지 않습니다. 일반 이미지 입력은 [PDF 도구](/ko/features/creating-pdfs/)에서 안내합니다.
