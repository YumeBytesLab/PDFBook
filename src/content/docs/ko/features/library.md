## 로컬 파일 가져오기

**라이브러리**에서 **책 추가**로 책을 추가하거나 **동기화 경로 추가**로 폴더를 등록합니다. PDF 확인과 표지 생성이 진행되며, 원본은 기존 위치에 남습니다.

폴더가 바뀌면 **파일 동기화**로 다시 스캔하세요. 시작 시 스캔으로도 갱신할 수 있습니다. 동기화 경로는 실시간 감시가 아니므로 나중에 추가한 파일은 새 스캔이 필요할 수 있습니다.

## 찾기 쉬운 책장 만들기

표지와 목록 보기 중 선택할 수 있습니다. 제목, 저자, 폴더, 태그, 0–5점 평점, 즐겨찾기, 읽지 않음·읽는 중·완료 상태로 정리하세요. 검색·필터·정렬로 원하는 책을 찾을 수 있습니다.

책 상세 정보에서 서지 정보, 설명, 책별 메모를 수정할 수 있습니다. 라이브러리에서 폴더를 바꾸는 것만으로 원본 PDF가 디스크의 다른 위치로 이동하지는 않습니다. 읽기 방향과 저장 위치도 책별로 기억할 수 있습니다.

## 책을 제거할 때

라이브러리 항목을 제거해도 원본 PDF는 디스크에 남습니다. 제거한 책은 나중의 자동 폴더 스캔에서 다시 추가되지 않도록 기록됩니다. 앱 밖에서 파일을 이동하거나 이름을 바꾸면 기존 경로가 끊길 수 있습니다. 원래 위치로 되돌리거나 새 위치에서 추가하세요.

## 무료 제한과 백업

무료 플랜은 **50권**, 유료 플랜은 권수 제한이 없습니다. 카탈로그·설정·표지는 기기에 저장되지만 책 원본의 복사본은 아닙니다. 앱 데이터와 원본 PDF 폴더를 모두 백업하세요. 외장 드라이브도 포함해야 합니다. 자세한 절차는 [파일과 개인정보](/ko/privacy/)에 있습니다.
