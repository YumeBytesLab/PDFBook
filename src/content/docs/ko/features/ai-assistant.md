## 제공업체 설정

Bookie는 선택적으로 사용하는 독서 도우미입니다. **설정 → AI**에서 Ollama, OpenAI, Anthropic(Claude), OpenRouter, Gemini 중 선택하세요. API 키나 로컬 Ollama 주소를 설정한 뒤 사용 가능한 모델을 고릅니다.

클라우드 제공업체에서는 데이터 공유 안내를 확인합니다. PDFBook에는 외부 AI 구독이나 API 크레딧이 포함되지 않습니다. 페이지 이미지 등 요청에 제공업체 요금이 별도로 발생할 수 있습니다.

## 로컬 Ollama

컴퓨터에서 Ollama를 실행하고 호환 모델을 설치하세요. AI 탭에서 서버 URL과 모델 목록을 확인합니다. 목록이 비어 있으면 서버 실행과 모델 설치를 점검하세요. 서버 주소가 로컬일 때 AI 요청이 기기 안에서 처리됩니다. 원격 주소는 원격 서비스입니다.

## 채팅과 문서 도구

도우미를 열어 질문을 보냅니다. 무료 사용자도 채팅할 수 있습니다. 페이지·표지 읽기와 앱 조작 도구에는 유료 플랜이 필요합니다. PDF를 열었다고 문서 전체가 자동으로 모델에 제공되지는 않습니다.

페이지 도구는 텍스트, 렌더링한 이미지 또는 둘 다 전달할 수 있습니다. 스캔과 도표에는 이미지를 이해하는 모델이 필요합니다. 앱 작업은 활성화한 도구와 권한에 따라 달라집니다. AI 답변은 틀릴 수 있으므로 실제 페이지와 대조하세요.

## 클라우드 전송 내용

메시지, 대화 문맥, 책 정보, 요청한 문서 텍스트나 페이지 이미지가 설정한 제공업체에 전송될 수 있습니다. 보내고 싶지 않은 자료에는 로컬 모델을 선택하거나 AI 없이 읽으세요. [개인정보](/ko/privacy/)와 [플랜](/ko/plans-and-licenses/)도 확인하세요.
