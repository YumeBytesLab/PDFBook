## 이미지로 PDF 만들기

1. **생성기**에서 **이미지 추가** 또는 **폴더 선택**를 선택합니다.
2. JPG/PNG를 추가하고 페이지 순서를 확인합니다. 폴더는 파일명의 자연 정렬로 가져오므로 출력 전에 순서를 조절하세요.
3. 용지 크기, 맞춤 방식, 여백을 선택하고 필요하면 열기 암호를 설정합니다.
4. **PDF 생성**을 선택하고 저장 위치를 지정합니다.

암호화한 출력에는 설정한 암호가 필요합니다. Creator는 이미지를 입력받으며 WebP나 다른 PDF의 임의 페이지 가져오기는 지원하지 않습니다.

## 문서와 전자책 변환

**변환기**에서 파일과 출력 폴더를 선택해 변환하세요. 성공한 PDF를 라이브러리에 추가하는 옵션도 있습니다.

지원 확장자는 EPUB/KEPUB, MOBI, AZW/AZW3/KF8, DOCX, MD/Markdown, TXT/Text, HTML/HTM, CBZ/CBR입니다. 리더는 변환된 PDF를 열며 EPUB을 직접 읽지 않습니다. DRM 보호 파일은 건너뛰고, 복잡한 레이아웃은 달라질 수 있습니다. 원본을 정리하기 전에 결과를 확인하세요.

## 포함된 이미지 추출

**추출기**에서 **PDF 선택**을 선택해 미리보기를 기다립니다. 필요한 이미지를 고르거나 전부 PNG로 저장하세요. 암호가 있는 PDF는 암호 입력을 요청합니다.

추출 대상은 내장 이미지 객체입니다. 전체 페이지 이미지 내보내기나 페이지 범위를 새 PDF로 분할하는 기능은 아닙니다. 문자와 벡터 선만 있는 문서는 추출 결과가 없을 수 있습니다. 다른 앱의 보이는 페이지를 모으려면 지원 환경에서 [화면 캡처](/ko/features/screen-capture/)를 사용하세요.
