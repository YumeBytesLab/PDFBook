## 책에 맞는 레이아웃

**라이브러리** 또는 **리더**에서 PDF를 엽니다. 도구 모음에서 **페이지 넘김**과 **세로 스크롤**을 전환하세요. 페이지 넘김에서는 한 페이지 또는 두 페이지 펼침을 선택할 수 있습니다.

만화는 표시 설정에서 오른쪽에서 왼쪽으로 읽기를 선택하세요. 읽기 방향은 책별로 저장할 수 있어 서로 다른 방향의 책을 같은 라이브러리에서 관리할 수 있습니다. 스캔 크기가 맞지 않으면 확대·축소를 조절하고, 페이지 번호로 원하는 곳으로 이동하세요.

## 찾고 다시 돌아오기

텍스트 검색에는 PDF의 검색 가능한 텍스트 레이어가 필요합니다. 이미지뿐인 스캔에 OCR을 추가하는 기능은 없습니다. 목차는 PDF 자체에 포함된 항목을 보여 줍니다.

현재 페이지를 북마크하고 이름을 붙이면 북마크 패널에서 돌아올 수 있습니다. **설정 → 리더**에서 읽기 위치 기억을 켜면 마지막 위치부터 이어집니다.

## 다른 작업 옆에서 읽기

집중 모드는 주변 인터페이스를 숨깁니다. 플로팅 리더는 항상 위에 표시되는 창으로, 메모나 다른 앱 옆에 두고 읽을 때 편리합니다.

첫 무료 플로팅 세션은 시간제한이 없고, 이후 매월 **실제 읽기 시간 60분**이 제공됩니다. UTC 기준 월초에 초기화됩니다. Pro·Lifetime은 이 시간제한을 없앱니다. [플랜](/ko/plans-and-licenses/)을 확인하세요.

## 암호와 메모

보호된 PDF에는 문서 암호를 입력하며, 해당 책에 대해 기억할 수도 있습니다. 라이브러리 메모는 책 전체에 붙습니다. PDF 페이지의 하이라이트·그리기·주석 기능은 제공하지 않습니다. 표시 문제는 [문제 해결](/ko/troubleshooting/)에서 확인하세요.
