---
title: "Get back to reading"
description: "Resolve missing files, search and rendering problems, conversion errors, capture limitations and license or AI connection issues."
---

## A book no longer opens

Check that the original PDF still exists at the saved location and that external drives are connected. Restore a moved file or add it from its new location. Re-scan a sync path after adding files. Catalog entries do not contain a backup copy of each PDF.

For a password prompt, enter the document's actual password. A license key is not a PDF password.

## Text search or page display looks wrong

Image-only scans cannot be searched without a text layer; OCR is not included. A missing contents list can simply mean the PDF has no outline. For garbled or incomplete rendering, try the other performance engine in **Settings → Reader**, then reopen the document. Use a non-private sample if reporting a reproducible issue.

## A PDF tool fails

Creator accepts JPG/PNG images. Converter accepts its listed formats and skips DRM-protected files; verify the output folder is writable. Extractor saves embedded images, so vector-only pages may show no results. A successful extraction does not mean a complete page image was exported.

## Capture, AI or paid features are unavailable

Capture requires Windows or Linux X11; automatic page turning is a separate capability. For AI, check the provider key, selected model, network or local Ollama server, and whether the request requires a paid tool. For paid features, reconnect and verify the license, expiry and device limit.

## Send a report that helps

First check the app version and try the current release. Include **version, OS, CPU architecture, exact steps, expected result and actual result** in an [issue](https://github.com/YumeBytesLab/PDFBook/issues/new/choose). Do not post private PDFs, API keys, license keys or a complete data folder. For private support use [contact](https://pdfbook.app/contact); report vulnerabilities through the [security policy](https://github.com/YumeBytesLab/PDFBook/security/policy).
