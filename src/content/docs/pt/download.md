## Escolha o arquivo

Abra a **[versão oficial mais recente](https://github.com/YumeBytesLab/PDFBook/releases/latest)**. O nome completo inclui a versão e termina assim:

| Computador | Arquivo |
| --- | --- |
| Windows, Intel/AMD | `windows-x64-setup.exe` ou `windows-x64-portable.exe` |
| Windows on Arm | `windows-arm64-setup.exe` ou `windows-arm64-portable.exe` |
| Mac, Apple Silicon | `macos-arm64.dmg` |
| Mac, Intel | `macos-x64.dmg` |
| Linux, Intel/AMD | `linux-x64.AppImage` ou `linux-amd64.deb` |
| Linux, Arm | `linux-arm64.AppImage` ou `linux-arm64.deb` |

`x64`, `amd64` e o antigo `x86_64` indicam a mesma família. Windows exige Windows 10 build 19041 ou posterior, incluindo Windows 11.

## Windows

Setup faz uma instalação normal. Portable funciona sem instalar. As versões independentes não são assinadas e o Windows pode mostrar um aviso de editor ou reputação. Confirme a origem oficial antes de executar.

A distribuição pela Microsoft Store está em preparação. No Windows, use **Setup** ou **Portable**.

## macOS e Linux

Abra o DMG e arraste PDFBook para Applications. O macOS ainda não tem assinatura Developer ID nem notarização. Consulte a [Apple](https://support.apple.com/pt-br/102445) se houver bloqueio. No Linux, permita a execução do AppImage ou instale o deb pelo gerenciador de pacotes. A captura precisa de X11.

## Atualizações

Em **Configurações → Avançado**, verifique manualmente ou habilite a busca ao iniciar. Ao trocar de computador, guarde os PDFs e um backup dos dados do app. Depois [adicione o primeiro livro](/pt/getting-started/).
