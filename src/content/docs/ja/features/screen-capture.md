別のアプリに表示されたページを取り込み、PDFにまとめるツールです。**Creator**から開き、ウィンドウや画面、ページの範囲を選んで取り込みます。

## 対応環境

| 環境 | 現在の対応状況 |
| --- | --- |
| Windows | 画面取り込みに対応。自動ページ送りはネイティブのキー入力ヘルパーの利用可否による |
| Linux X11 | 画面取り込みに対応。自動ページ送りはヘルパーとCPUに依存する |
| Linux Wayland | 現在は未対応 |
| macOS | 現在の配布版では未対応 |

アプリが実行環境の対応状況を確認します。画面取り込みと自動ページ送りは別の機能なので、すべてのビルドで自動送りが使えるとは限りません。

## 取り込みの手順

1. 元のアプリで取り込みたいページを表示します。
2. ウィンドウを選び、単ページなら1範囲、見開きなら2範囲を指定します。
3. 枚数と待ち時間を設定します。自動送りが使える場合はページ送りのキーも選びます。
4. 取り込みを開始し、集まったページを確認してPDFを保存します。

実行中は **停止** ボタンか **Esc** キーで止められます。
