## Режим отображения

Откройте PDF из **Библиотека** или **Ридер**. На панели выберите **Перелистывание** или **Вертикальная прокрутка**. Для перелистывания доступны одна страница и разворот.

Для манги включите справа налево в настройках отображения. Направление сохраняется для книги. Используйте масштаб для нестандартных сканов и номер страницы для перехода.

## Поиск и сохранение места

Поиску нужен текстовый слой: OCR для сканов не добавляется. Оглавление берётся из самого PDF. Поставьте закладку, при желании назовите её и возвращайтесь через панель закладок.

В **Настройки → Ридер** включите запоминание позиции, чтобы продолжать с последнего места.

## Рядом с другой программой

Режим фокуса скрывает интерфейс. Плавающая читалка остаётся поверх окон. Первая бесплатная сессия не ограничена, затем доступны **60 активных минут в календарный месяц** со сбросом в начале месяца по UTC. Pro и Lifetime снимают это ограничение. См. [планы](/ru/plans-and-licenses/).

## Пароли и заметки

Введите пароль документа при запросе. Его можно запомнить для книги. Заметки относятся ко всей книге. Выделения, рисование и аннотации на страницах не предусмотрены. При неправильном отображении обратитесь к [решению проблем](/ru/troubleshooting/).
