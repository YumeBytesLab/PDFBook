## Tampilan dan bahasa

Buka **Pengaturan → Umum**. Pilih terang, gelap, atau sistem, warna, dan ukuran teks. Semua 12 bahasa serta pengulangan pengenalan tersedia di sini.

Aplikasi PDF bawaan mengikuti OS: Windows membuka pengaturan aplikasi default, macOS memakai Finder, Linux dapat menetapkan asosiasi bila didukung. Beberapa rilis Windows mandiri menampilkan thumbnail Explorer. Paket Store tidak menyertakan integrasi ini.

## Pembaca

Di **Pembaca**, atur mode awal, satu/dua halaman, arah, zoom, penyimpanan posisi, fokus, dan suara. Sebagian pilihan dapat berbeda per buku.

Opsi performa mengganti mesin PDF. Bila dokumen tergambar salah, coba mesin lain dan buka ulang. Satu mesin tidak selalu lebih baik untuk semua berkas.

## Pustaka

Di **Perpustakaan**, pilih urutan awal, buka dengan klik, dan buku subfolder. Pramuat dan konkurensi memengaruhi persiapan sampul. Kurangi konkurensi jika komputer sibuk.

## Data dan layanan

**Lanjutan** memuat pemeriksaan pembaruan dan **Buka folder data pengguna** untuk cadangan. Penyedia dan model di **AI**, aktivasi dan perangkat di **Lisensi**. Baca [AI](/id/features/ai-assistant/), [lisensi](/id/plans-and-licenses/), serta [privasi](/id/privacy/) untuk ketentuannya.
