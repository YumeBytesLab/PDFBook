## Pilih tata letak

Buka PDF dari **Perpustakaan** atau **Pembaca**. Bilah alat menyediakan **Balik halaman** dan **Gulir vertikal**. Mode pergantian halaman mendukung satu atau dua halaman.

Untuk manga, pilih kanan ke kiri dalam kontrol tampilan. Arah dapat disimpan per buku. Sesuaikan zoom untuk hasil pindai dan gunakan nomor halaman untuk berpindah.

## Cari dan simpan posisi

Pencarian memerlukan lapisan teks; OCR tidak ditambahkan ke gambar pindai. Daftar isi berasal dari PDF itu sendiri. Tandai halaman, beri nama bila perlu, dan kembali melalui panel penanda.

Aktifkan penyimpanan posisi di **Pengaturan → Pembaca** untuk meneruskan bacaan nanti.

## Membaca di samping aplikasi lain

Mode fokus menyembunyikan antarmuka. Pembaca mengambang selalu berada di atas. Sesi gratis pertama tidak dibatasi; sesudahnya ada **60 menit membaca aktif per bulan kalender**, direset pada awal bulan UTC. Pro dan Lifetime menghapus batas ini. Lihat [paket](/id/plans-and-licenses/).

## Kata sandi dan catatan

Masukkan kata sandi dokumen saat diminta; dapat diingat untuk buku tersebut. Catatan pustaka melekat pada seluruh buku. Sorotan, gambar tangan, dan anotasi halaman tidak disediakan. Untuk gangguan tampilan lihat [pemecahan masalah](/id/troubleshooting/).
