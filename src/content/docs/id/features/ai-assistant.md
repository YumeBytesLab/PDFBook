## Hubungkan penyedia

Bookie bersifat opsional. Di **Pengaturan → AI**, pilih Ollama, OpenAI, Anthropic (Claude), OpenRouter, atau Gemini. Masukkan kunci API atau alamat Ollama, lalu pilih model yang tersedia.

Penyedia cloud meminta konfirmasi pemberitahuan data. PDFBook tidak menyertakan langganan atau kredit AI; teks dan gambar halaman dapat dikenai biaya oleh penyedia.

## Ollama lokal

Jalankan Ollama dan pasang model yang cocok. Periksa URL serta daftar model di tab AI. Jika kosong, cek server dan model terpasang. Permintaan tetap di komputer bila server yang diatur lokal; alamat jarak jauh tetap layanan jarak jauh.

## Chat dan alat dokumen

Pengguna gratis dapat mengobrol. Membaca halaman atau sampul dan melakukan tindakan aplikasi memerlukan paket berbayar. Membuka PDF tidak otomatis memberikan seluruh dokumen kepada model.

Alat dapat memberi teks, gambar halaman, atau keduanya. Hasil pindai memerlukan model yang memahami gambar. Tindakan tergantung alat serta izin yang diaktifkan. Bandingkan jawaban dengan halaman asli karena AI bisa salah.

## Data yang dikirim

Pesan, konteks, metadata buku, serta teks atau gambar yang diminta dapat dikirim ke penyedia cloud pilihan. Anda bisa memakai model lokal atau membaca tanpa AI. Lihat [privasi](/id/privacy/) dan [paket](/id/plans-and-licenses/).
