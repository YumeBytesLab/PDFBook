## Tambahkan dan pindai ulang

Di **Perpustakaan**, gunakan **Tambah buku** untuk buku atau **Tambah jalur sinkronisasi** untuk folder. PDF diperiksa dan sampul dibuat. Aslinya tetap di tempat semula.

Jalankan **Sinkronkan file** setelah folder berubah. Pemindaian saat mulai juga dapat memperbarui. Jalur sinkronisasi bukan pemantauan berkelanjutan di latar belakang.

## Temukan bacaan berikutnya

Beralih antara sampul dan daftar. Gunakan judul, penulis, folder, tag, nilai 0–5 bintang, favorit, dan status Belum dibaca / Sedang dibaca / Selesai. Pencarian, filter, dan urutan mempersempit pilihan.

Detail buku memungkinkan pengeditan informasi, deskripsi dan catatan. Pengelompokan dalam folder pustaka tidak memindahkan PDF di disk. Arah dan posisi membaca dapat disimpan per buku.

## Menghapus entri

Menghapus entri tetap menyimpan PDF asli dan mencegah impor otomatis berikutnya. Jika berkas dipindah atau diganti nama di luar aplikasi, pulihkan jalur atau tambahkan dari lokasi barunya.

## Batas dan cadangan

Paket gratis mendukung **50 buku**, paket berbayar menghapus batas. Katalog, pengaturan, dan sampul disimpan lokal tetapi bukan salinan buku. Cadangkan folder PDF serta data aplikasi, termasuk berkas pada drive eksternal. Langkahnya ada di [berkas dan privasi](/id/privacy/).
