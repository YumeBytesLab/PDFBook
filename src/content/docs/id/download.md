## Pilih berkas yang tepat

Buka **[rilis resmi terbaru](https://github.com/YumeBytesLab/PDFBook/releases/latest)**. Nama lengkap memuat versi dan berakhir seperti berikut:

| Komputer | Berkas |
| --- | --- |
| Windows, Intel/AMD | `windows-x64-setup.exe` atau `windows-x64-portable.exe` |
| Windows on Arm | `windows-arm64-setup.exe` atau `windows-arm64-portable.exe` |
| Mac, Apple Silicon | `macos-arm64.dmg` |
| Mac, Intel | `macos-x64.dmg` |
| Linux, Intel/AMD | `linux-x64.AppImage` atau `linux-amd64.deb` |
| Linux, Arm | `linux-arm64.AppImage` atau `linux-arm64.deb` |

`x64`, `amd64`, dan nama lama `x86_64` merujuk keluarga yang sama. Windows memerlukan Windows 10 build 19041 atau lebih baru, termasuk Windows 11.

## Windows

Setup memasang aplikasi. Portable berjalan tanpa pemasangan. Rilis mandiri belum ditandatangani sehingga Windows mungkin menampilkan peringatan penerbit atau reputasi. Periksa sumber resmi sebelum menjalankan.

Distribusi Microsoft Store sedang disiapkan. Untuk Windows, pilih **Setup** atau **Portable**.

## macOS dan Linux

Buka DMG dan seret PDFBook ke Applications. Versi Mac belum memiliki tanda tangan Developer ID atau notarisasi. Lihat [panduan Apple](https://support.apple.com/id-id/102445) jika diblokir. Izinkan eksekusi AppImage, atau pasang deb melalui pengelola paket. Tangkapan layar memerlukan X11.

## Pembaruan

Di **Pengaturan → Lanjutan**, periksa manual atau aktifkan pemeriksaan saat mulai. Saat pindah komputer, simpan PDF asli dan cadangan data aplikasi. Setelah itu [tambahkan buku pertama](/id/getting-started/).
