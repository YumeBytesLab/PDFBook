## Choisir le fichier

Ouvrez la **[dernière version officielle](https://github.com/YumeBytesLab/PDFBook/releases/latest)**. Le nom complet comporte la version et se termine ainsi :

| Ordinateur | Fichier |
| --- | --- |
| Windows, Intel/AMD | `windows-x64-setup.exe` ou `windows-x64-portable.exe` |
| Windows on Arm | `windows-arm64-setup.exe` ou `windows-arm64-portable.exe` |
| Mac, Apple Silicon | `macos-arm64.dmg` |
| Mac, Intel | `macos-x64.dmg` |
| Linux, Intel/AMD | `linux-x64.AppImage` ou `linux-amd64.deb` |
| Linux, Arm | `linux-arm64.AppImage` ou `linux-arm64.deb` |

`x64`, `amd64` et l’ancien `x86_64` désignent la même famille. Windows nécessite Windows 10 build 19041 ou ultérieur, y compris Windows 11.

## Windows

Setup effectue une installation classique. Portable fonctionne sans installation. Les versions autonomes ne sont pas signées et Windows peut afficher un avertissement d’éditeur ou de réputation. Vérifiez leur origine officielle avant de les exécuter.

La distribution Microsoft Store est en préparation. Sous Windows, choisissez **Setup** ou **Portable**.

## macOS et Linux

Ouvrez le DMG et glissez PDFBook dans Applications. Les versions macOS n’ont ni signature Developer ID ni notarisation. Consultez [Apple](https://support.apple.com/fr-fr/102445) si le lancement est bloqué. Sous Linux, autorisez l’exécution de l’AppImage ou installez le deb avec le gestionnaire de paquets. La capture demande X11.

## Mettre à jour

Dans **Paramètres → Avancé**, vérifiez manuellement ou activez les contrôles au démarrage. Conservez les PDF et une sauvegarde des données lors d’un changement d’ordinateur. Passez ensuite au [premier livre](/fr/getting-started/).
