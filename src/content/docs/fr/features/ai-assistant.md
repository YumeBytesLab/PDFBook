## Choisir un fournisseur

Bookie est facultatif. Dans **Paramètres → IA**, choisissez Ollama, OpenAI, Anthropic (Claude), OpenRouter ou Gemini. Saisissez votre clé API ou l’adresse Ollama et choisissez un modèle.

Pour le cloud, confirmez l’avis de partage des données. PDFBook n’inclut ni abonnement ni crédits IA ; le fournisseur peut facturer textes et images de pages.

## Ollama local

Démarrez Ollama et installez un modèle compatible. Vérifiez l’URL et la liste dans l’onglet IA. Une liste vide invite à contrôler le serveur et le modèle installé. Les requêtes restent sur l’ordinateur lorsque le serveur configuré est local ; une adresse distante demeure un service distant.

## Conversation et outils

Les utilisateurs gratuits peuvent discuter. Lire une page ou une couverture et effectuer des actions dans l’application demande une offre payante. Ouvrir un PDF ne transmet pas automatiquement l’intégralité du document.

Les outils fournissent texte, image de page ou les deux. Les scans nécessitent un modèle capable d’interpréter les images. Les actions dépendent des outils et autorisations activés. Comparez les réponses à la page, car elles peuvent être fausses.

## Données envoyées

Messages, contexte, informations du livre et textes ou images demandés peuvent partir vers le fournisseur cloud choisi. Vous pouvez utiliser un modèle local ou lire sans IA. Consultez la [confidentialité](/fr/privacy/) et les [offres](/fr/plans-and-licenses/).
