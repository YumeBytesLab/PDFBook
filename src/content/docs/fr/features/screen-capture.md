## Vérifier les possibilités

La capture fonctionne sous Windows et Linux X11. Elle est désactivée sous macOS et Wayland. Le changement automatique de page dépend séparément du module clavier, du processeur et des autorisations. Linux ARM64 peut capturer sous X11 mais ne possède pas ce module automatique.

L’application indique les possibilités. Les images JPG/PNG enregistrées restent utilisables lorsque la capture est indisponible.

## Capturer une fenêtre

1. Ouvrez **Créateur → Capturer depuis l'écran**.
2. Choisissez la fenêtre et recadrez barres d’outils et marges inutiles.
3. Réglez le nombre de pages et le délai. Si l’automatisme est proposé, choisissez touche et sens, puis laissez le temps au rendu de l’autre application.
4. Lancez, vérifiez les images et ordonnez-les dans Creator avant d’exporter.

Gardez la fenêtre disponible. Une vue minimisée, masquée ou qui n’a pas changé ne donne pas la page suivante voulue.

## Images répétées ou vides

Testez d’abord une page. Vérifiez la sélection et augmentez le délai si une animation est photographiée. L’absence d’automatisme n’implique pas une capture défectueuse : lisez les capacités et choisissez l’entrée d’images ou un autre mode disponible.

La capture enregistre la vue visible, sans importer le document source, ajouter un OCR ou récupérer des pages cachées. Voir les [outils PDF](/fr/features/creating-pdfs/) pour l’export classique.
