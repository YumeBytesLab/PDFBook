## Choisir une présentation

Ouvrez un PDF depuis **Bibliothèque** ou **Lecteur**. La barre d’outils permet **Changement de page** ou **Défilement vertical**. Le mode page propose une page simple ou double.

Pour les mangas, sélectionnez droite à gauche dans les commandes d’affichage. Le sens peut être mémorisé par livre. Ajustez le zoom des scans et utilisez le numéro de page pour vous déplacer.

## Retrouver un passage

La recherche demande une couche de texte. Aucun OCR n’est ajouté aux scans. Le sommaire affiche celui que possède le PDF. Posez un signet sur la page, nommez-le si nécessaire et retrouvez-le dans le panneau des signets.

Dans **Paramètres → Lecteur**, activez la mémorisation de position pour continuer là où vous étiez.

## Lire à côté d’une autre application

Le mode concentration masque l’interface. Le lecteur flottant ouvre une fenêtre toujours au premier plan. La première session gratuite est sans limite, puis vous disposez de **60 minutes de lecture active par mois civil**, avec remise à zéro en UTC. Pro et Lifetime suppriment ce plafond. Voir les [offres](/fr/plans-and-licenses/).

## Mots de passe et notes

Saisissez le mot de passe du document demandé. Vous pouvez le mémoriser pour ce livre. Les notes sont rattachées au livre entier. Le surlignage, le dessin et les annotations sur la page ne sont pas proposés. Consultez le [dépannage](/fr/troubleshooting/) en cas d’affichage incorrect.
