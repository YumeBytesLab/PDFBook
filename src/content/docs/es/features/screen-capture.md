## Comprueba la compatibilidad

La captura está disponible en Windows y Linux X11; está desactivada en macOS y Wayland. El paso automático es una función separada y depende del asistente de teclado, la arquitectura y los permisos. Linux ARM64 puede capturar en X11, pero no tiene el asistente de paso automático.

La aplicación muestra las capacidades disponibles. Puedes crear PDF con JPG/PNG guardados aunque la captura no esté disponible.

## Realiza una captura

1. Abre **Creador → Capturar desde pantalla**.
2. Elige la ventana y recorta barras o márgenes que no quieras.
3. Configura páginas y espera entre capturas. Si hay paso automático, elige dirección/tecla y deja que la otra app termine de dibujar.
4. Inicia, revisa las imágenes y ordénalas en Creator antes de exportar.

Mantén accesible la ventana objetivo. Una vista minimizada, sin cambio de página u oculta no produce la siguiente página deseada.

## Páginas repetidas o vacías

Prueba primero una página. Verifica la ventana y aumenta la espera si capturas una animación. Si falta el paso automático, revisa el aviso de capacidades; no significa que toda la captura falle. Usa la entrada de imágenes u otro flujo disponible.

La captura registra la pantalla visible; no importa el documento original, no añade OCR ni recupera páginas ocultas. Consulta [herramientas PDF](/es/features/creating-pdfs/) para la exportación normal.
