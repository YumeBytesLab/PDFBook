## Elige la presentación

Abre un PDF desde **Biblioteca** o **Lector**. Alterna **Paso de páginas** y **Desplazamiento vertical** en la barra de herramientas. El modo de paso de página permite una página o un pliego doble.

Para manga, cambia la dirección a derecha a izquierda en los controles de visualización. Puede guardarse por libro. Ajusta el zoom para los escaneos y usa el número de página para saltar a una posición.

## Encuentra y guarda tu lugar

La búsqueda necesita una capa de texto. No se añade OCR a los escaneos. El índice solo muestra el que incluya el PDF. Añade un marcador a la página, asígnale un nombre si quieres y vuelve desde el panel de marcadores.

Activa la memoria de posición en **Ajustes → Lector** para retomar la lectura.

## Lee junto a otras aplicaciones

El modo de concentración oculta la interfaz. El lector flotante abre una ventana siempre visible. La primera sesión gratuita no tiene límite. Después dispones de **60 minutos activos por mes natural**, con reinicio mensual en UTC. Pro y Lifetime no tienen ese límite. Consulta los [planes](/es/plans-and-licenses/).

## Contraseñas y notas

Introduce la contraseña del documento cuando se solicite. Puedes recordarla para ese libro. Las notas pertenecen al libro completo. No hay resaltado, dibujo ni anotaciones sobre las páginas. Para problemas de visualización consulta [solución de problemas](/es/troubleshooting/).
