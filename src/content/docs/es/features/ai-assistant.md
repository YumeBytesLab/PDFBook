## Configura un proveedor

Bookie es opcional. En **Ajustes → IA** elige Ollama, OpenAI, Anthropic (Claude), OpenRouter o Gemini. Introduce tu clave API o la dirección de Ollama y selecciona un modelo disponible.

Los proveedores cloud requieren confirmar el aviso de datos. PDFBook no incluye suscripción ni créditos de IA. El proveedor puede cobrar por texto e imágenes de página.

## Usa Ollama en tu equipo

Ejecuta Ollama e instala un modelo compatible. Comprueba la URL y la lista de modelos en la pestaña IA. Si está vacía, revisa el servidor y la instalación del modelo. Las solicitudes permanecen en tu equipo cuando el servidor configurado es local. Una URL remota sigue siendo un servicio remoto.

## Chat y herramientas

Los usuarios gratuitos pueden conversar. Las herramientas para leer páginas o portadas y actuar en la app requieren un plan de pago. Abrir un PDF no entrega automáticamente su contenido completo al modelo.

Las herramientas pueden proporcionar texto, una imagen de página o ambos. Los escaneos requieren un modelo con visión. Las acciones dependen de herramientas y permisos habilitados. Contrasta las respuestas con la página, porque pueden ser incorrectas.

## Privacidad

Las solicitudes cloud pueden contener mensajes, contexto, metadatos del libro y texto o imágenes solicitados. Se envían al proveedor configurado. Puedes usar un modelo local o leer sin IA. Consulta [privacidad](/es/privacy/) y [planes](/es/plans-and-licenses/).
