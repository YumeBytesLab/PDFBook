## El libro no abre

Revisa que el PDF original exista en la ruta guardada y que la unidad esté conectada. Restituye la ubicación o añade el archivo desde la nueva. Vuelve a escanear carpetas tras añadir PDF. El catálogo no contiene una copia del original. Si se pide contraseña, es la del documento, no la licencia.

## Búsqueda o presentación incorrecta

Un escaneo sin texto no se puede buscar: no hay OCR. La falta de índice puede ser normal. Para caracteres o páginas mal dibujados prueba otro motor en **Ajustes → Lector** y abre de nuevo el PDF.

## Herramientas y funciones

Creator acepta JPG/PNG. Converter necesita formatos compatibles y omite DRM. Comprueba permisos de salida. Extractor guarda imágenes incrustadas, no páginas completas: texto y vectores pueden no dar resultados.

La captura requiere Windows o X11, y el paso automático depende de otra capacidad. Para IA revisa clave, modelo, red u Ollama y si necesitas una herramienta de pago. Para licencias comprueba conexión, caducidad, reloj y dispositivos.

## Envía un informe

Prueba primero la versión actual. En un [informe de error](https://github.com/YumeBytesLab/PDFBook/issues/new/choose), incluye versión, OS, CPU, pasos, resultado esperado y real. Usa un ejemplo no privado. No publiques PDF personales, claves o datos completos de la app. Para ayuda privada usa [contacto](https://pdfbook.app/contact). Para vulnerabilidades, la [política de seguridad](https://github.com/YumeBytesLab/PDFBook/security/policy).
