## Trova un libro e riprendi a leggere

Trasforma le cartelle di PDF in una libreria visiva per libri, manga, articoli e documenti scansionati. Attiva la memoria della posizione per riprendere da dove eri rimasto.

| Per… | Puoi usare… |
| --- | --- |
| **Libri e manga** | Cambio pagina o scorrimento verticale, pagina singola o doppia e lettura da destra a sinistra. |
| **Articoli e consultazione** | Ricerca nel testo, segnalibri, indice incluso nel PDF e lettore flottante sempre in primo piano. |
| **La tua raccolta** | Cartelle, tag, valutazioni, preferiti, stato di lettura e note per libro. Ripeti la scansione delle cartelle monitorate per importare nuovi file. |
| **Operazioni sui PDF** | Crea PDF da immagini JPG/PNG, converti documenti ed e-book supportati ed estrai immagini incorporate. |
| **IA facoltativa** | Collega il tuo provider o un modello Ollama locale. |

![Lettore PDFBook con un libro su due pagine e i comandi di lettura](../public/images/reader-en.webp)

## Scaricare e installare

Scegli il file per il tuo sistema e la tua CPU nell’**[ultima versione](https://github.com/YumeBytesLab/PDFBook/releases/latest)**.

| Sistema | Formato | CPU |
| --- | --- | --- |
| Windows 10 / 11 | Setup / Portable | x64 / ARM64 |
| macOS | DMG | Apple Silicon (ARM64) / Intel (x64) |
| Linux | AppImage / deb | x64 / amd64 / ARM64 |

Le versioni autonome per Windows non sono firmate; quelle per macOS non sono firmate con Developer ID né autenticate da Apple. Consulta la [guida all’installazione](https://wiki.pdfbook.app/it/download/). La distribuzione su Microsoft Store è in preparazione. Su Windows usa **Setup o Portable**.

## Inizia gratuitamente

Il piano gratuito supporta **fino a 50 libri**. Il lettore flottante offre una prima sessione senza limiti, poi **60 minuti di lettura attiva per mese di calendario**. Pro / Lifetime eliminano entrambi i limiti.

La chat IA usa il tuo provider. La lettura delle pagine con IA e gli strumenti per le azioni nell’app richiedono un piano a pagamento. I costi del provider sono separati; non è incluso un abbonamento IA. [Piani e prezzi](https://pdfbook.app/it#pricing).

## File e privacy

Lettura, libreria, creazione e conversione di PDF funzionano sul tuo computer. **Non serve un account per leggere.** Se attivi l’IA cloud, messaggi, contesto e testi o immagini di pagina richiesti vengono inviati al provider configurato. Con un modello Ollama locale, queste richieste restano sul dispositivo. [Privacy (in inglese)](https://pdfbook.app/privacy).
