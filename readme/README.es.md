## Funciones

Convierte tus carpetas de PDF en una biblioteca visual para libros, manga, artículos y documentos escaneados. Activa la memoria de posición para retomar la lectura donde la dejaste.

| Para… | Puedes usar… |
| --- | --- |
| **Libros y manga** | Paso de página o desplazamiento vertical, una o dos páginas y lectura de derecha a izquierda. |
| **Artículos y consultas** | Búsqueda de texto, marcadores, índice incluido en el PDF y un lector flotante siempre visible. |
| **Tu colección** | Carpetas, etiquetas, valoraciones, favoritos, estado de lectura y notas por libro. Vuelve a escanear las carpetas supervisadas para importar archivos nuevos. |
| **Tareas con PDF** | Crea PDF a partir de JPG/PNG, convierte documentos y libros electrónicos compatibles y extrae imágenes incrustadas. |
| **IA opcional** | Conecta tu propio proveedor o un modelo local de Ollama. |

![Lector de PDFBook con un libro a doble página y controles de lectura](../public/images/reader-en.webp)

## Descarga e instalación

Elige el archivo para tu sistema y CPU en la **[última versión](https://github.com/YumeBytesLab/PDFBook/releases/latest)**.

| Sistema | Formato | CPU |
| --- | --- | --- |
| Windows 10 / 11 | Setup / Portable | x64 / ARM64 |
| macOS | DMG | Apple Silicon (ARM64) / Intel (x64) |
| Linux | AppImage / deb | x64 / amd64 / ARM64 |

Las versiones independientes de Windows no están firmadas. Las de macOS no tienen firma Developer ID ni notarización. Consulta la [guía de instalación](https://wiki.pdfbook.app/es/download/). La versión de Microsoft Store está en preparación. En Windows, usa **Setup o Portable**.

## Tus archivos y tu privacidad

La lectura, la biblioteca, la creación y la conversión de PDF se procesan en tu equipo. **No necesitas una cuenta para leer.** Si activas IA en la nube, se envían al proveedor configurado los mensajes, el contexto y el texto o las imágenes de página que solicites analizar. Con un modelo local de Ollama, esas solicitudes permanecen en tu dispositivo. [Privacidad (en inglés)](https://pdfbook.app/privacy).
