## Trouvez un livre et reprenez votre lecture

Transformez vos dossiers de PDF en bibliothèque visuelle : livres, mangas, articles et documents numérisés. Activez la mémorisation de la position pour reprendre là où vous vous êtes arrêté.

| Pour… | Vous disposez de… |
| --- | --- |
| **Livres et mangas** | Pages à tourner ou défilement vertical, page simple ou double, lecture de droite à gauche. |
| **Articles et références** | Recherche de texte, signets, sommaire intégré au PDF et lecteur flottant toujours au premier plan. |
| **Votre collection** | Dossiers, étiquettes, notes d’évaluation, favoris, état de lecture et notes par livre. Relancez l’analyse des dossiers surveillés pour importer les nouveaux fichiers. |
| **Travaux sur PDF** | Création depuis des images JPG/PNG, conversion de documents et livres numériques compatibles, extraction des images intégrées. |
| **IA facultative** | Connexion à votre propre fournisseur ou à un modèle Ollama local. |

![Lecteur PDFBook affichant un livre en double page avec ses commandes de lecture](../public/images/reader-en.webp)

## Télécharger et installer

Choisissez le fichier correspondant à votre système et à votre processeur dans la **[dernière version](https://github.com/YumeBytesLab/PDFBook/releases/latest)**.

| Système | Format | Processeur |
| --- | --- | --- |
| Windows 10 / 11 | Setup / Portable | x64 / ARM64 |
| macOS | DMG | Apple Silicon (ARM64) / Intel (x64) |
| Linux | AppImage / deb | x64 / amd64 / ARM64 |

Les versions autonomes Windows ne sont pas signées ; les versions macOS ne sont ni signées avec Developer ID ni notariées. Consultez le [guide d’installation](https://wiki.pdfbook.app/fr/download/). La distribution Microsoft Store est en préparation. Sous Windows, choisissez **Setup ou Portable**.

## Commencez gratuitement

L’offre gratuite accepte **jusqu’à 50 livres**. Le lecteur flottant propose une première session sans limite, puis **60 minutes de lecture active par mois civil**. Pro / Lifetime suppriment ces deux limites.

Le chat IA utilise votre fournisseur. La lecture de pages par l’IA et les outils d’action dans l’application nécessitent une offre payante. Les frais du fournisseur sont distincts ; aucun abonnement IA n’est inclus. [Offres et tarifs](https://pdfbook.app/fr#pricing).

## Vos fichiers et votre vie privée

La lecture, la bibliothèque, la création et la conversion de PDF fonctionnent sur votre ordinateur. **Aucun compte n’est nécessaire pour lire.** Si vous activez une IA dans le cloud, les messages, le contexte et les textes ou images de pages demandés sont transmis au fournisseur configuré. Avec un modèle Ollama local, ces requêtes restent sur votre appareil. [Confidentialité (en anglais)](https://pdfbook.app/privacy).
