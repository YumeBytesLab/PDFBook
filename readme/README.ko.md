## 다음 책을 고르고, 읽던 페이지부터

폴더에 쌓인 PDF를 표지로 고르는 책장으로 정리하세요. 책, 만화, 논문, 스캔 자료를 읽고, 읽기 위치 기억을 켜면 지난번 페이지부터 이어 볼 수 있습니다.

| 이런 순간에 | PDFBook으로 할 수 있는 일 |
| --- | --- |
| **책과 만화** | 페이지 넘김·세로 스크롤, 한 페이지·두 페이지 펼침, 오른쪽에서 왼쪽으로 읽기. |
| **논문과 자료** | 텍스트 검색, 북마크, PDF 자체 목차, 항상 위에 표시되는 플로팅 리더. |
| **라이브러리 정리** | 폴더, 태그, 평점, 즐겨찾기, 독서 상태, 책별 메모. 감시 폴더를 다시 스캔해 새 파일을 가져옵니다. |
| **PDF 작업** | JPG/PNG로 PDF 만들기, 지원 문서·전자책 형식 변환, PDF에 포함된 이미지 추출. |
| **선택형 AI** | 직접 설정한 제공업체나 로컬 Ollama 모델 연결. |

![두 페이지 펼침과 읽기 도구를 보여 주는 PDFBook 리더](../public/images/reader-en.webp)

## 다운로드와 설치

**[최신 릴리스](https://github.com/YumeBytesLab/PDFBook/releases/latest)**에서 OS와 CPU에 맞는 파일을 선택하세요.

| OS | 형식 | CPU |
| --- | --- | --- |
| Windows 10 / 11 | Setup / Portable | x64 / ARM64 |
| macOS | DMG | Apple Silicon (ARM64) / Intel (x64) |
| Linux | AppImage / deb | x64 / amd64 / ARM64 |

Windows 독립 배포판은 서명되지 않았으며, macOS 버전은 Developer ID 서명·공증이 적용되지 않았습니다. [설치 가이드 (영어)](https://wiki.pdfbook.app/download/)를 확인하세요. Microsoft Store 버전은 준비 중입니다. `.appx`는 서명되지 않은 제출용 패키지이므로 Windows에서는 **Setup 또는 Portable**을 사용하세요.

## 무료로 책장을 시작하세요

무료 라이브러리는 **최대 50권**을 지원합니다. 플로팅 리더는 첫 세션에 시간제한이 없고, 이후 매월 **실제 읽기 시간 60분**이 제공됩니다. Pro / Lifetime은 이 두 제한을 없앱니다.

AI 채팅은 본인이 설정한 제공업체를 사용합니다. AI 페이지 읽기·앱 조작 도구에는 유료 플랜이 필요합니다. 제공업체 요금은 별도이며 PDFBook에 AI 구독은 포함되지 않습니다. [플랜과 가격](https://pdfbook.app/ko#pricing).

## 파일과 개인정보

PDF 읽기, 라이브러리 저장, PDF 생성·변환은 PC에서 처리하며 **읽기에 계정이 필요하지 않습니다**. 클라우드 AI를 켜면 메시지, 대화 문맥, 요청한 문서 텍스트나 페이지 이미지가 설정한 제공업체에 전송됩니다. 로컬 Ollama 모델을 사용하면 해당 AI 요청도 기기 안에서 처리할 수 있습니다. [개인정보 처리방침 (영어)](https://pdfbook.app/privacy).

### 이 저장소에 관하여
