## Найдите книгу и продолжите чтение

Превратите папки с PDF в наглядную библиотеку книг, манги, статей и сканов. Включите сохранение позиции, чтобы возвращаться к странице, на которой остановились.

| Для чего | Возможности |
| --- | --- |
| **Книги и манга** | Перелистывание или вертикальная прокрутка, одна страница или разворот, чтение справа налево. |
| **Статьи и справочники** | Поиск текста, закладки, встроенное оглавление PDF и плавающая читалка поверх других окон. |
| **Ваша коллекция** | Папки, теги, оценки, избранное, статус чтения и заметки к книгам. Повторное сканирование отслеживаемых папок импортирует новые файлы. |
| **Работа с PDF** | Создание PDF из JPG/PNG, конвертация поддерживаемых документов и электронных книг, извлечение встроенных изображений. |
| **ИИ по желанию** | Подключение своего провайдера или локальной модели Ollama. |

## Скачать и установить

В **[последнем релизе](https://github.com/YumeBytesLab/PDFBook/releases/latest)** выберите файл для своей ОС и процессора.

| Система | Формат | Процессор |
| --- | --- | --- |
| Windows 10 / 11 | Setup / Portable | x64 / ARM64 |
| macOS | DMG | Apple Silicon (ARM64) / Intel (x64) |
| Linux | AppImage / deb | x64 / amd64 / ARM64 |

Отдельные сборки Windows не подписаны; сборки macOS не имеют подписи Developer ID и не прошли нотариальное заверение Apple. См. [руководство по установке (на английском)](https://wiki.pdfbook.app/download/). Версия для Microsoft Store готовится. Файлы `.appx` — неподписанные пакеты для отправки в Store; в Windows используйте **Setup или Portable**.

## Начните бесплатно

Бесплатная библиотека вмещает **до 50 книг**. Первая сессия плавающей читалки не ограничена по времени, затем доступны **60 минут активного чтения в календарный месяц**. Pro / Lifetime снимают оба ограничения.

Чат с ИИ использует вашего провайдера. Чтение страниц с помощью ИИ и инструменты действий в приложении требуют платного плана. Услуги провайдера оплачиваются отдельно; подписка на ИИ не включена. [Планы и цены](https://pdfbook.app/ru#pricing).

## Файлы и конфиденциальность

Чтение PDF, библиотека, создание и конвертация работают на вашем компьютере. **Для чтения не нужна учётная запись.** При включении облачного ИИ сообщения, контекст и запрошенный текст документов или изображения страниц отправляются выбранному провайдеру. С локальной моделью Ollama эти ИИ-запросы остаются на устройстве. [Конфиденциальность (на английском)](https://pdfbook.app/privacy).
