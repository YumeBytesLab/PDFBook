## Ein Buch finden und weiterlesen

Mach aus PDF-Ordnern eine übersichtliche Bibliothek für Bücher, Manga, Fachartikel und Scans. Mit aktivierter Positionsspeicherung liest du dort weiter, wo du aufgehört hast.

| Für … | Das bietet PDFBook |
| --- | --- |
| **Bücher und Manga** | Umblättern oder vertikales Scrollen, Einzel- oder Doppelseiten und Lesen von rechts nach links. |
| **Artikel und Nachschlagewerke** | Textsuche, Lesezeichen, das im PDF enthaltene Inhaltsverzeichnis und ein schwebender Reader im Vordergrund. |
| **Deine Sammlung** | Ordner, Tags, Bewertungen, Favoriten, Lesestatus und Notizen pro Buch. Überwachte Ordner erneut einlesen, um neue Dateien zu importieren. |
| **PDF-Aufgaben** | PDFs aus JPG/PNG erstellen, unterstützte Dokumente und E-Books konvertieren und eingebettete Bilder extrahieren. |
| **Optionale KI** | Eigenen Anbieter oder ein lokales Ollama-Modell verbinden. |

![PDFBook-Reader mit einer Doppelseite und Lesesteuerung](../public/images/reader-en.webp)

## Herunterladen und installieren

Wähle in der **[neuesten Veröffentlichung](https://github.com/YumeBytesLab/PDFBook/releases/latest)** die Datei für dein Betriebssystem und deine CPU.

| System | Format | CPU |
| --- | --- | --- |
| Windows 10 / 11 | Setup / Portable | x64 / ARM64 |
| macOS | DMG | Apple Silicon (ARM64) / Intel (x64) |
| Linux | AppImage / deb | x64 / amd64 / ARM64 |

Die eigenständigen Windows-Versionen sind unsigniert; die macOS-Versionen sind weder mit Developer ID signiert noch notarisiert. Siehe [Installationsanleitung](https://wiki.pdfbook.app/de/download/). Die Microsoft-Store-Veröffentlichung wird vorbereitet. `.appx`-Dateien sind unsignierte Einreichungspakete; unter Windows bitte **Setup oder Portable** verwenden.

## Kostenlos anfangen

Der kostenlose Tarif umfasst **bis zu 50 Bücher**. Die erste Sitzung im schwebenden Reader ist unbegrenzt, danach gibt es **60 Minuten aktive Lesezeit pro Kalendermonat**. Pro / Lifetime heben beide Grenzen auf.

Der KI-Chat nutzt deinen eigenen Anbieter. KI-Seitenlesen und Werkzeuge für App-Aktionen benötigen einen kostenpflichtigen Tarif. Anbietergebühren fallen separat an; ein KI-Abo ist nicht enthalten. [Tarife und Preise](https://pdfbook.app/de#pricing).

## Dateien und Datenschutz

PDF-Lesen, Bibliothek, PDF-Erstellung und Konvertierung laufen auf deinem Computer. **Zum Lesen brauchst du kein Konto.** Aktivierst du Cloud-KI, werden Nachrichten, Gesprächskontext und angefragte Dokumenttexte oder Seitenbilder an den eingestellten Anbieter gesendet. Mit einem lokalen Ollama-Modell bleiben diese KI-Anfragen auf deinem Gerät. [Datenschutz (Englisch)](https://pdfbook.app/privacy).
