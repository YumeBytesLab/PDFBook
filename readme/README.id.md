## Fitur

Ubah folder PDF menjadi pustaka visual untuk buku, manga, artikel, dan dokumen hasil pemindaian. Aktifkan penyimpanan posisi baca untuk melanjutkan dari halaman terakhir.

| Untuk… | Anda dapat menggunakan… |
| --- | --- |
| **Buku dan manga** | Pergantian halaman atau gulir vertikal, satu atau dua halaman, serta arah baca dari kanan ke kiri. |
| **Artikel dan referensi** | Pencarian teks, penanda halaman, daftar isi bawaan PDF, dan pembaca mengambang yang selalu di atas. |
| **Koleksi Anda** | Folder, tag, penilaian, favorit, status membaca, dan catatan per buku. Pindai ulang folder yang dipantau untuk mengimpor berkas baru. |
| **Pekerjaan PDF** | Buat PDF dari gambar JPG/PNG, konversi dokumen dan buku elektronik yang didukung, serta ekstrak gambar yang tertanam. |
| **AI opsional** | Hubungkan penyedia Anda sendiri atau model Ollama lokal. |

![Pembaca PDFBook dengan tampilan dua halaman dan kontrol membaca](../public/images/reader-en.webp)

## Unduh dan pasang

Pilih berkas yang sesuai dengan OS dan CPU Anda dari **[rilis terbaru](https://github.com/YumeBytesLab/PDFBook/releases/latest)**.

| Sistem | Format | CPU |
| --- | --- | --- |
| Windows 10 / 11 | Setup / Portable | x64 / ARM64 |
| macOS | DMG | Apple Silicon (ARM64) / Intel (x64) |
| Linux | AppImage / deb | x64 / amd64 / ARM64 |

Versi mandiri Windows belum ditandatangani. Versi macOS belum ditandatangani dengan Developer ID atau dinotarisasi. Lihat [panduan pemasangan](https://wiki.pdfbook.app/id/download/). Distribusi Microsoft Store sedang disiapkan. Untuk Windows gunakan **Setup atau Portable**.

## Berkas dan privasi

Pembacaan PDF, penyimpanan pustaka, pembuatan, dan konversi berjalan di komputer Anda. **Tidak perlu akun untuk membaca.** Jika AI cloud diaktifkan, pesan, konteks percakapan, serta teks dokumen atau gambar halaman yang diminta akan dikirim ke penyedia yang dipilih. Dengan model Ollama lokal, permintaan AI tersebut tetap di perangkat Anda. [Privasi (bahasa Inggris)](https://pdfbook.app/privacy).
