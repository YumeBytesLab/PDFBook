## Encontre um livro e continue a leitura

Transforme pastas de PDFs em uma biblioteca visual para livros, mangás, artigos e documentos digitalizados. Ative a memória de posição para retomar de onde parou.

| Para… | Você pode usar… |
| --- | --- |
| **Livros e mangás** | Virada de página ou rolagem vertical, página única ou dupla e leitura da direita para a esquerda. |
| **Artigos e consultas** | Busca de texto, marcadores, sumário presente no PDF e leitor flutuante sempre em primeiro plano. |
| **Sua coleção** | Pastas, tags, avaliações, favoritos, status de leitura e notas por livro. Escaneie novamente as pastas monitoradas para importar novos arquivos. |
| **Tarefas com PDF** | Crie PDFs com imagens JPG/PNG, converta documentos e e-books compatíveis e extraia imagens incorporadas. |
| **IA opcional** | Conecte seu próprio provedor ou um modelo local do Ollama. |

![Leitor do PDFBook exibindo um livro em página dupla e os controles de leitura](../public/images/reader-en.webp)

## Baixar e instalar

Escolha o arquivo para seu sistema e CPU na **[versão mais recente](https://github.com/YumeBytesLab/PDFBook/releases/latest)**.

| Sistema | Formato | CPU |
| --- | --- | --- |
| Windows 10 / 11 | Setup / Portable | x64 / ARM64 |
| macOS | DMG | Apple Silicon (ARM64) / Intel (x64) |
| Linux | AppImage / deb | x64 / amd64 / ARM64 |

As versões independentes para Windows não são assinadas; as versões para macOS não têm assinatura Developer ID nem notarização. Veja o [guia de instalação](https://wiki.pdfbook.app/pt/download/). A distribuição pela Microsoft Store está em preparação. Os arquivos `.appx` são pacotes de envio sem assinatura; no Windows, use **Setup ou Portable**.

## Comece gratuitamente

O plano gratuito permite **até 50 livros**. O leitor flutuante tem a primeira sessão sem limite e depois **60 minutos de leitura ativa por mês-calendário**. Pro / Lifetime removem os dois limites.

O chat com IA usa seu provedor. As ferramentas de leitura de páginas e ações no aplicativo exigem um plano pago. As taxas do provedor são separadas; o PDFBook não inclui assinatura de IA. [Planos e preços](https://pdfbook.app/pt#pricing).

## Seus arquivos e sua privacidade

Leitura, biblioteca, criação e conversão de PDFs funcionam no seu computador. **Você não precisa de conta para ler.** Ao ativar IA na nuvem, mensagens, contexto e textos ou imagens de páginas solicitados são enviados ao provedor configurado. Com um modelo local do Ollama, essas solicitações ficam no dispositivo. [Privacidade (em inglês)](https://pdfbook.app/privacy).
